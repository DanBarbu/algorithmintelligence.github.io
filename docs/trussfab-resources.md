# TrussFab — Resources

TrussFab is a research project from the Hasso Plattner Institute (HPI) for fabricating large-scale structures using PET plastic bottles connected by 3D-printed hubs.

## Official Project Resources

| Resource Type | Link | Description |
|---|---|---|
| Official Project Page | [hpi.de/baudisch/projects/trussfab.html](https://hpi.de/baudisch/projects/trussfab.html) | Primary project page with workflow, paper, and contact info |
| Research Paper (ACM DL) | [dl.acm.org/citation.cfm?id=3026016](http://dl.acm.org/citation.cfm?id=3026016) | "TrussFab: Fabricating Sturdy Large-Scale Structures on Desktop 3D Printers" (CHI'17) |
| Paper PDF | Available via project page | Full paper PDF download |
| Thingiverse Collection | [thingiverse.com/HassoPlattnerInstitute_HCI/collections/trussfab](https://www.thingiverse.com/HassoPlattnerInstitute_HCI/collections/trussfab) | 3D-printable hub STL files and pre-designed projects (chair, etc.) |
| Instructables Tutorial | [How to Connect PET Bottles for TrussFab Structures](https://www.instructables.com/How-to-Connect-PET-Bottles-for-TrussFab-Structures/) | Step-by-step guide for connecting PET bottles (dry ice inflation, screwing, taping) |
